# Selcuk AI Assistant

An end-to-end, multilingual Retrieval-Augmented Generation (RAG) assistant engineered to streamline university career workflows and academic data retrieval.

## 🚀 Architecture & Tech Stack
- **AI/RAG Pipeline**: Built with **LangChain** and **FAISS** for rapid vector similarity search.
- **Local Local LLM Processing**: Integrated with **Ollama** for secure, low-latency, on-premise inference.
- **Backend API**: Engineered using **Python** & **FastAPI** to handle high-throughput, concurrent user queries.
- **Frontend Core**: Delivered a robust cross-platform mobile interface using **Dart** & **Flutter**.
- **Containerization**: Fully scalable and reproducible via **Docker**.

## 📊 Key Highlights
- **Multilingual Support**: Real-time interaction capability (Turkish/English) adapting dynamically to the user's language preference.
- **Secure Retrieval**: Processes domain-specific documents securely, eliminating hallucination rates present in standard LLM web-search.
- **Seamless UX**: Responsive, clean UI designed for intuitive text and voice interaction parameters.

🧠 LaBSE Embedding Modeli

Neden LaBSE?

  • 109 dil desteği (Türkçe dahil)
  • Google tarafından geliştirilmiş
  • Cross-lingual similarity
  • 768-dim yoğun vektörler

Alternatifler

  • mBERT: Daha düşük performans
  • OpenAI Embeddings: API bağımlılığı
  • XLM-R: Daha yavaş

# LaBSE Kullanımı

from sentence_transformers import SentenceTransformer

 

model = SentenceTransformer('LaBSE')

 

# Türkçe sorgu embedding

query = "Sınav tarihleri nedir?"

embedding = model.encode(query)
